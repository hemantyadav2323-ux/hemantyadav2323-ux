# 🚀 Featured Project

## 🛡️ HySeer — AI-Based Operator Safety & Alertness Monitoring

**HySeer** is a computer-vision based operator monitoring system designed to improve workplace safety through real-time fatigue and interaction monitoring.

### 🔍 Key Features

* 👁️ **EAR-based eye closure & blink detection**
* 😮 **MAR-based yawning detection**
* 🧭 **Head-pose estimation**
* 📊 **Real-time fatigue scoring**
* 🚨 **Safety alerts**
* 🧠 **Emotion recognition**
* ✋ **Hand-gesture based operator check-ins**
* 📈 **Live monitoring statistics**
* 📝 **Session logging**

### 🛠️ Technology

`Python` `OpenCV` `MediaPipe` `Computer Vision` `AI`
